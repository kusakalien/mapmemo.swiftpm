MapMemo サポート

MapMemo をご利用いただきありがとうございます。MapMemo は、お店ごとの「一番お得な支払い方法」を地図にメモできるアプリです。ご質問・ご不明な点がありましたら、本ページをご確認ください。

使い方

  • メモを追加する：地図上のお店のピンをタップし、「ブランド名」とメモ（例: ○○カードで最大7%還元）を入力して保存します。
  • 全国の同じお店に反映：「ローソン」のようにブランド名で登録すると、同じブランド名で始まるお店すべてに同じメモが表示されます。
  • 近くのお店のお知らせ：位置情報を許可すると、近くにあるメモ済みのお店を画面上部のバナーでお知らせします。
  • メモの確認・編集・削除：画面右上のリストボタンから、登録済みのメモを一覧で確認・編集・削除できます。

よくある質問

地図にお店のピンが表示されません

お店の検索にはインターネット接続が必要です。通信環境をご確認ください。また、地図を広域に表示している（ズームアウトしすぎている）とピンは表示されません。お店が見える程度までズームインしてください。

現在地が表示されません / 近くのお店が通知されません

位置情報の利用が許可されているかご確認ください。iOS の「設定」→「プライバシーとセキュリティ」→「位置情報サービス」→「MapMemo」から、「このAppの使用中のみ許可」を選択してください。

「ローソン」にメモしたのに別のお店にも表示されます / されません

メモは「お店の名前がブランド名で始まる」場合に表示されます（前方一致）。意図しないお店に表示される場合はブランド名をより具体的に、表示されない場合はブランド名を短く（例:「ローソン」）調整してください。

メモを6件以上登録できません

無料でご登録いただけるメモは5件までです。6件目以降は、アプリ内課金「メモ無制限」をご購入いただくと、件数の制限なくメモを追加できます。

購入したのに無制限にならない / 機種変更しました

課金画面の「購入を復元」をタップしてください。同じ Apple ID であれば、購入済みの「メモ無制限」が復元されます。

メモのデータはどこに保存されますか？

メモはお使いの端末内にのみ保存されます。当社のサーバーには送信されません。アプリを削除するとメモも削除されますのでご注意ください。
