# mapmemo.swiftpm

マップ上にお店のメモを残せる iOS アプリです。

例えば「ローソンでは ○○ クレカ」「セブンイレブンでは ×× クレカが一番お得」など、
お店ごとのお得な決済方法を地図上にメモとして記録できます。

## 主な機能

- 🗺 **地図上に実在のお店を表示** — コンビニ・スーパー・薬局・飲食店などのピンを表示
- ✍️ **お店のピンをタップしてメモ** — お得な決済方法などをそのお店に記録（メモ済みのお店は赤いピン＋吹き出し表示）
- 🏪 **ブランド単位でメモを共有** — 「ローソン」にメモすると、全国のローソンに同じメモが反映（前方一致）
- 📍 **現在地のお店を検出** — 位置情報を取得し、近く（約80m以内）のメモ済みお店を画面上部のバナーで通知
- 💳 **アプリ内課金** — 無料では5件まで、それ以上は「メモ無制限」課金（StoreKit 2）で解除

## 使い方

1. アプリを起動すると位置情報の利用許可を求められます（許可すると現在地が表示されます）。
2. 地図上のお店のピンをタップし、ブランド名（例: ローソン）とメモを入力して保存します。
3. 同じブランド名を含むお店すべてに、そのメモが反映されます。
4. 右上のリストボタンから登録済みメモの一覧・編集・削除ができます。

## 技術構成

- **対象**: iOS 18 以降
- **UI**: SwiftUI（MapKit の最新 `Map` API）
- **位置情報**: CoreLocation（`@Observable` を用いた `LocationManager`）
- **永続化**: SwiftData（`@Model` / `@Query`）
- **課金**: StoreKit 2（非消耗型課金 `com.kusakalien.mapmemo.unlimited`）

## アプリ内課金について

無料プランではメモを5件まで登録でき、6件目以降は非消耗型課金「メモ無制限」で解除します。

実際に購入を行うには、App Store Connect に同じプロダクト ID（`com.kusakalien.mapmemo.unlimited`）の
非消耗型 In-App Purchase を登録する必要があります。登録前は商品情報を取得できないため、課金画面には
「商品情報を読み込めませんでした」と表示されます（5件の上限制御自体は機能します）。
