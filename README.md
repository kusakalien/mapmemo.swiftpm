# mapmemo.swiftpm

マップ上にお店のメモを残せる iOS アプリです。

例えば「ローソンでは ○○ クレカ」「セブンイレブンでは ×× クレカが一番お得」など、
お店ごとのお得な決済方法を地図上にメモとして記録できます。

## 主な機能

- 🗺 **地図上にメモを表示** — 登録したお店のメモをピンで表示
- ✍️ **メモの作成・編集・削除** — ユーザーが自由にお店のメモを管理
- 📍 **現在地のお店を検出** — 位置情報を取得し、近く（約80m以内）のお店のメモを画面上部のバナーで通知

## 使い方

1. アプリを起動すると位置情報の利用許可を求められます（許可すると現在地周辺のメモが表示されます）。
2. 地図をタップ、または右下の「現在地にメモ」ボタンからメモを追加できます。
3. 右上のリストボタンから登録済みメモの一覧を確認できます。
4. ピンやバナー、一覧をタップするとメモの編集・削除ができます。

## 技術構成

- **対象**: iOS 18 以降
- **UI**: SwiftUI（MapKit の最新 `Map` API）
- **位置情報**: CoreLocation（`@Observable` を用いた `LocationManager`）
- **永続化**: SwiftData（`@Model` / `@Query`）

## 開発・実行

iPad の Swift Playgrounds でこのリポジトリをプロジェクトとして開いて実行・テストできます。
